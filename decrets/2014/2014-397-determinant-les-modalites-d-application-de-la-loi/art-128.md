# Article 128

- Le plan de developpement communautaire mentionne a I'article 124 du Code minier couvre notamment les domaines d'intervention suivants :
Ie developpement d'intiastructures et d'equipements de base ;
Ie developpernent des services sociaux de base et du cadre de vie ;
la promotion de I'emploi ;
Ie developpement de I'economie locale;
Ie developpement du capital hurnain.
