# Décret n° 2019-266 du 27 mars 2019 fixant les modalités d'application au Domaine Foncier Rural Coutumier de la loi n° 98-750 du 23 décembre 1998. Toute personne, tout groupement informel de personnes physiques dûment identifiées, se prévalant de droits sur le Domaine Foncier Rural coutumier, doit faire constater ces droits.
