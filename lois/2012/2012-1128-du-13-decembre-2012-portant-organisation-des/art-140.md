# Article 140

Le contrôle de tutelle s'exerce par voie :
1- d'approbation ;
2- d'autorisation préalable ;
3- de démission d'office ;
4- de dissolution ;
5- de suspension ;
6- de révocation ;
7 - de constatation de nullité ;
8- d'annulation ;
9- de substitution ;
10- d'inspection ;
11- de traduction devant la juridiction compétente.
