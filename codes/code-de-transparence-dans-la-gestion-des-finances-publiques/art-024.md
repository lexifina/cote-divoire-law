# Article 24

- La réglementation par l'administration publique du secteur bancaire et financier doit être fondée sur des objectifs clairement définis.
Tous les actifs de l'État sous forme de participations dans le secteur bancaire doivent être identifiés dans les documents budgétaires. L'acquisition, la vente d'actifs et les objectifs visés par les pouvoirs publics doivent être clairement expliqués dans la documentation budgétaire.
