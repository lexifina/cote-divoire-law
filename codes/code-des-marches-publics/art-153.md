# Article 153

- Code de conduite Les fonctionnaires, agents publics ou privés des autorités contractantes ou des autres structures intervenant dans la passation, le contrôle, l'exécution, le règlement ou la régulation des marchés publics sont soumis à un Code de conduite et de déontologie défini par décret.
