# Article 2

Les dispositionS de la presente loi s'appliquent sans prejudice de celles relevant notamment des domaines specifiques regis par la loi relative au regime du foncier rural, Ie Code de I'eau, la loi relative a la sCirete nucleaire et a la protection contre les rayonnements ionisants, Ie Code de la Sante publique, la loi relative aux collectivites territoriales, Ie Code'de I'Environnement, Ie Code forestier, Ie Code civil, Ie Code penal. les legislations fiscales et douanieres et tous les autres Codes dont les dispositions peuvent s'appliquer directement ou indirectement a I'activite miniere, a condition qu'elles ne soient pas contraires a celies de la presente loi.
