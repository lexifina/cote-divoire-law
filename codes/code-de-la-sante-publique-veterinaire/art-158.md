# Article 158

— Les vétérinaires sont seuls qualifiés pour mettre fin à la souffrance d’un animal par euthanasie. Ils sont tenus d’en dresser procès-verbal.
Toutefois, les techniciens vétérinaires peuvent le faire sous la responsabilité d’un vétérinaire. Dans ce cas, le procès-verbal est dressé par le vétérinaire.
